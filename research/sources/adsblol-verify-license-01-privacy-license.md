# ADSB.lol official privacy and license page — verification capture

**URL:** https://www.adsb.lol/privacy-license/  
**Checked:** 2026-09-30  
**Evidence method:** direct HTTPS retrieval from the research workspace; HTML text reviewed locally

## Relevant official text

- The page says the service is intended to be used “as is.”
- Under “Disclaimer of Warranties,” it says ADSB.lol will use best efforts to provide accurate data, but the data is provided on an “as is” basis and no warranty is made for accuracy, timeliness, completeness, reliability, or availability. It says ADSB.lol receives data from multiple sources it may or may not control and that data integrity/accuracy cannot be guaranteed.
- Under “License,” it says: “By sending data to feed.adsb.lol / in.adsb.lol, you agree, to the extent possible under law, to waive all copyright and related or neighboring rights to the data you are sharing, under the CC0 license.”
- The page provides the contact address `info [at] adsb.lol`.

## What this page does not say

This page does not itself give a public-display permission for third-party applications, a numeric API limit, a freshness/latency SLA, a cache-retention rule, or an interpretation of how ODbL applies to normalized API observations. The CC0 statement is specifically about data sent to the feeder endpoints; it is not a statement that public API responses are CC0.

**Unresolved legal/terms question:** Whether Signalwatch may publicly display, normalize, or temporarily cache API observations is not resolved by this page alone.
