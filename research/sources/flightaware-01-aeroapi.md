# FlightAware official AeroAPI product page

**URL:** https://www.flightaware.com/commercial/aeroapi/  
**Checked:** 2026-09-30  
**Evidence type:** direct retrieval of official provider product and pricing page

The page returned HTTP 200. It describes AeroAPI as an on-demand, usage-based API for current and historical flight data, including flight status, tracks, positions, speed, and altitude. Its sample code uses an API key in the `x-apikey` header.

The page describes derivative-work storage and distribution by tier: Personal for personal/academic use; Standard for business or business-to-consumer purposes; Premium for business-to-consumer commercial and business-to-business commercial purposes. Pricing is usage/result-set based and plan-dependent. The page does not establish that a particular public map or arbitrary geographic polling pattern is covered by a tier.

The same product page advertises global coverage combining FlightAware ADS-B receivers and space-based ADS-B. This is a provider claim, not an independently measured coverage guarantee.
