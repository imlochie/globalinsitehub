# Visual identity — recorded direction

Status: **recorded direction, not a work order.** No checkpoint is scheduled
against it yet. It is written down so that UI work done for other reasons
moves toward it rather than away from it.

---

## 1. The target feeling

A **live global instrument**: density, telemetry, spatial hierarchy,
live-state language, strong identity.

**Explicitly not by copying OSIRIS.** OSIRIS remains research material only.
The target is the *class of object* — an instrument that is visibly reading
the world right now — not any particular implementation of it.

## 2. The planet is the product identity

**The globe is the hero of the composition, not one card in a SaaS
dashboard.**

This is the single most consequential item here, because it inverts the
default layout instinct. A dashboard that happens to contain a globe reads as
a reporting tool. A planet with instrumentation around it reads as a live
system. Signalwatch is the second thing.

Layout target:

- **header** — UTC, LIVE state, layers, status
- **centre** — planet / map, dominant
- **bottom strip** — live feed, incidents, weather, traffic, fuel

## 3. Palette

Near-black / graphite ground, with:

| Colour | Semantic job |
|---|---|
| electric cyan | primary live instrumentation |
| warm amber | attention, caution, degraded state |
| deep violet / magenta | planetary and weather phenomena |
| restrained green | genuinely live and healthy states only |

**Each colour has a semantic job. Not neon everywhere.** A palette where
everything glows carries no information; the point of a restrained ground is
that a lit element *means* something. Green in particular is reserved — it
must not become decoration, because it is the colour the three-axis badge
rule (`admitted` / `reachable` / `active`) depends on to mean "actually
live".

## 4. Intelligence sectors

**Demote, do not delete.**

"Intelligence sectors" stops being the application's identity and becomes
*one way of organising capabilities*. The existing sector model and its
illustrative markers stay; what changes is that they no longer define what
Signalwatch looks like or what it is for.

## 5. Relationship to the honesty rules

Visual identity does not get to override source semantics. Specifically:

- a strong live aesthetic must never make an **unavailable** source look
  active;
- "no source here" must stay visually distinct from "clear", however good the
  render looks;
- `ACTIVE` / `AVAILABLE` / `NO SOURCE HERE` remain three distinct states and
  must not be collapsed into one colour.

An instrument that looks live while reporting nothing is worse than a plain
one that says so.
